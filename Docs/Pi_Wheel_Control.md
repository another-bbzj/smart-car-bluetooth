# 车载香橙派轮速命令接入（开发中）

比赛时车载香橙派自行计算左右轮目标，F407 执行现有轮速闭环；不依赖比赛时蓝牙遥控。当前实现为编译期选择，默认仍为蓝牙调试：

- `CAR_COMMAND_SOURCE_PI=0`：UART4 接收原有蓝牙控制协议；USART3 接收视觉观测协议。
- `CAR_COMMAND_SOURCE_PI=1`：USART3 / PB11 / 115200 8N1 接收原有蓝牙轮速控制协议；UART4 的输入被丢弃。USART3 不再接收 `Vision_Interface.md` 的视觉观测协议，两种协议不能混用。UART4 遥测输出维持现状；USART3 没有 ACK。

香橙派的 3.3V TTL TX 接 F407 PB11，双方共地。串口设备名依实际板型核对。`ARM`、`STOP` 和 `WHEELS` 帧格式见 `Car_Core.h` 或 `Tools/car_host.py`。比赛程序自行发送 `ARM`，并持续发送最新左右轮 RPM；`STOP` 停止。在香橙派命令配置下，`HEARTBEAT` 不刷新看门狗，500 ms 没有合法 `WHEELS` 则故障停车。500 ms 是现有软件上限，尚未证明适合实际车速，不能作为端到端延迟保证。PWM 清零也不等于车辆立即停止。

此版本仅完成命令来源选择和看门狗语义，未提供香橙派比赛发送程序或双向状态确认。协议没有序号、采集时间、端到端时限和会话确认，无法证明命令未在发送端或串口队列中过期；必须在赛前补齐或验证整个链路，不能把该配置直接视为可上赛道的系统。现有速度参考规划在目标高频变化时可能进展很慢，需修复和测试后才能用于视觉连续控制。轮径、轮距、左右轮 CPR 和实际停车距离均需实测。断路通行、赛道状态和自主发车由上位机与后续系统设计实现。
